# Request a Custom Trace Pack

Trace Pro Community Runtime uses signed Trace Packs containing configured checks. If the included Demo does not cover your workflow, you can describe the problem in a public issue so EDARIT can discuss whether a Custom Pack may fit.

**This is a public discussion. Do not upload or paste documents, spreadsheets, personal information, financial or institutional records, customer files, credentials, or proprietary business data.** The public request form asks for a problem description only.

## Useful starting information

- What kinds of documents do you process?
- What repetitive review task would you like to simplify?
- Which fields or checks matter?
- Do the checks use Excel or CSV reference data?
- About how many distinct document layouts are involved?
- Do you need Windows or Debian?

Share only information you are authorized to disclose. Do not include names, account numbers, invoice values, reference rows, or other sensitive examples in the public issue. A high-level, sanitized description is enough for an initial scope discussion.

## What happens next

EDARIT can assess the described workflow, identify questions and possible product gaps, and discuss scope before any work begins. A Custom Pack may configure detections, highlights, annotations, reference lookups, and review evidence using capabilities supported by the Runtime. OCR or unsupported checks may require separate product work.

Any confidential sample collection requires a separately agreed private transfer method. Do not use public GitHub issues or comments to transfer files. This request does not promise that a workflow can be supported, that results will be correct, or that work will be performed at a particular price or schedule.

Use the [Custom Pack request form](https://github.com/edarit/edarit-trace-pro-runtime/issues/new/choose) for a public, sanitized description only.
